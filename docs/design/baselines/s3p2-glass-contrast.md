# S3 P2 液态玻璃面板对比度基线

- 任务：T-S3P2-B-04
- 范围：白名单 6 处 `.glass-panel` 的正文可读性
- 结论：正文（`--ink` / `--ink-light`）在两个最差背景样本上均 ≥ 4.5:1；`--ink-muted` 仅 2.97:1，禁止用作正文

## 1. 固定样本

| 编号 | 页面 | 位置 | 取色方式 |
|---|---|---|---|
| S1 | `/` 首页海报轮播 | 海报暗部（轮播图深色区域） | DevTools 取色器，缩放 100%，Chrome 稳定版 |
| S2 | `/exhibition/taihedian` | 深色舞台边缘（`viewerArea` 暗部） | 同上 |

采样色（取色值，sRGB）：

| 样本 | 背景色 |
|---|---|
| S1 | `#1B1714` = (27, 23, 20) |
| S2 | `#0F0D0B` = (15, 13, 11) |

## 2. 面板等效色

`.glass-panel` 底色 token：`--surface-glass-heavy: rgba(247, 243, 235, 0.95)`，即纸白 `#F7F3EB` 以 95% 不透明度叠加在背景上。

等效色公式（逐通道）：

```
C_eff = 0.95 × C_paper + 0.05 × C_bg
```

| 样本 | 计算 | 等效色 |
|---|---|---|
| S1 | R=0.95×247+0.05×27=236；G=0.95×243+0.05×23=232；B=0.95×235+0.05×20=224 | `#ECE8E0` |
| S2 | R=0.95×247+0.05×15=235；G=0.95×243+0.05×13=232；B=0.95×235+0.05×11=224 | `#EBE8E0` |

## 3. 对比度计算

文字色 token：

- 正文：`--ink: #2C2C2C` = (44, 44, 44)
- 次级正文：`--ink-light: #5A5252` = (90, 82, 82)
- 说明性小字（禁止作正文）：`--ink-muted: #8C8580` = (140, 133, 128)

WCAG 2.x 相对亮度：

```
L = 0.2126·R' + 0.7152·G' + 0.0722·B'
C' ≤ 0.04045 ? C/12.92 : ((C+0.055)/1.055)^2.4
CR = (L_light + 0.05) / (L_dark + 0.05)
```

| 组 | 等效底色 | 文字色 | 对比度 | 判定 |
|---|---|---|---|---|
| S1 × `--ink` | `#ECE8E0` | `#2C2C2C` | **11.43:1** | ✅ ≥ 4.5:1 |
| S1 × `--ink-light` | `#ECE8E0` | `#5A5252` | **6.22:1** | ✅ ≥ 4.5:1 |
| S2 × `--ink` | `#EBE8E0` | `#2C2C2C` | **11.41:1** | ✅ ≥ 4.5:1 |
| S2 × `--ink-light` | `#EBE8E0` | `#5A5252` | **6.21:1** | ✅ ≥ 4.5:1 |

参考（纯纸白底）：

| 底色 | 文字色 | 对比度 |
|---|---|---|
| `#F7F3EB` | `#2C2C2C` | 12.62:1 |
| `#F7F3EB` | `#5A5252` | 6.87:1 |

## 4. `--ink-muted` 判定依据

| 组 | 等效底色 | 文字色 | 对比度 | 判定 |
|---|---|---|---|---|
| S1 × `--ink-muted` | `#ECE8E0` | `#8C8580` | 2.97:1 | ❌ < 4.5:1 |
| S2 × `--ink-muted` | `#EBE8E0` | `#8C8580` | 2.97:1 | ❌ < 4.5:1 |

即使按大字号（≥ 18.66px 粗体 / ≥ 24px）的 3:1 门槛，2.97:1 仍不达标。因此 `.glass-panel` 内正文与按钮文字只允许 `--ink` / `--ink-light`，`--ink-muted` 仅可用于非关键说明（如时间戳、辅助计数），且不得承担主要阅读任务。

## 5. 复现步骤

1. 启动生产构建：`npm run build && npm run server`（或 `npm run dev`）。
2. 打开 `/` 与 `/exhibition/taihedian`，将窗口宽度保持桌面档（≥ 1280px），缩放 100%。
3. 在 S1 轮播暗部、S2 舞台暗部打开 DevTools 取色器记录背景色。
4. 按第 2 节公式计算 `C_eff`，按第 3 节公式计算对比度。
5. 若任一正文组合 < 4.5:1，视为回归，需提升 `--surface-glass-heavy` 不透明度或改用更深文字色。
