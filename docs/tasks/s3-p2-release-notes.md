# S3 P2 发布说明与口径公告

- 版本：S3 P2（视频 / 液态玻璃 / SEO / 排行榜 / 课堂模式 / UGC 阻断 / 横向门禁）
- 日期：2026-11-23
- 适用范围：对外答复、运营口径、发布评审

## 1. 排行榜口径（P2-3）

- "答对题数" = **去重答对题数**（同一用户同一题只计一次，取首次结果）；
- 积分（赏银）**不参与排序**，仅作成长记录；
- 同分按"首次答对时间"升序，名次稳定；
- 历史数据按"同题首次结果"回填，因此**历史名次可能变化**，原始答题记录保留；
- 未成年人模式 / 退出公开榜：不展示精确名次，昵称统一为"营造学徒"，无头像；
- 高频提交触发限流（默认 30 次 / 60 秒）；限流时提示"操作过快，稍后可继续"，不影响浏览。

## 2. SEO 边界（P2-6）

- 保证：分享页 `og:*`/`twitter:*` 元信息、`robots.txt`、`sitemap.xml`、规范化地址（canonical）、结构化数据（JSON-LD）正确；
- 不承诺：首页 / 列表页正文被搜索引擎完整收录；本版本**不提供 SSR**；
- `/search`、`/profile`、`/curator` 返回 `X-Robots-Tag: noindex, follow`。

## 3. sitemap 口径（Q1）

- 只收录**规范地址**：`/exhibition/:id`、`/encyclopedia?term=:id`、`/routes/:id`（及其列表页）；
- `/share/*` 为别名，**不重复收录**；
- 只收录已发布内容；sitemap 生成失败返回 503，不返回空站点地图。

## 4. 兜底图说明（R-S3-19）

- `images/brand/og-default.webp` 当前不存在，分享卡片与 JSON-LD 使用 `images/posters/gugong.webp` 作为兜底；
- 内容侧补齐品牌图后**无需改代码**自动切换（代码按存在性判断）；
- 视频封面优先 `poster_path`，缺失时使用同一兜底图，不使用 `og-default`。

## 5. 视频说明（P2-2）

- 有视频声明且可访问时才展示视频区；无声明、404、类型错误、超时均**不渲染视频节点**；
- 当前仓库可能全站无视频资源（`videos/` 目录为空），属**正常状态**，不出现空白框或错误提示；
- 静态服务支持 Range（拖动进度依赖 206 响应）。

## 6. UGC 说明（P2-5）

- **本期不交付 UGC 笔记公开**，全站无任何公开/发布/审核/举报入口；
- `/api/ugc/*` 全部 404（不返回 401/403，避免暴露存在性）；
- 解禁需满足 `docs/tasks/s3-p2-ugc-blocked-report.md` 中的条件，并另立项，不沿用本期编号。

## 7. 课堂模式说明（P2-4）

- 登录用户偏好跨设备保存；游客偏好保存在本机；
- 课堂只读链接（`?view=classroom&font=...&readonly=1`）只影响当前会话，不写存储、不改服务端偏好；
- 课堂模式下字号三档（标准 18px / 大 20px / 特大 22.4px，窄屏特大回退 20px），隐藏推荐、分享、社交与注册引导；
- 随堂练习**零写入**：不计分、不发徽章、不写答题记录与事实表。

## 8. 质量门禁

- `npm run test:client` / `npm run test:server` / `npm run test:contract` / `npm run schema:diff`；
- `npm run seo:check` 与 `npm run ugc:check` 必须退出码 0；
- 详细实测见 `docs/tasks/s3-p2-gate-report.md`。

## 9. 已知边界

- 不做真实压测、不做搜索引擎真机抓取模拟、不做真机机型矩阵；
- 帧率与投屏结论以人工清单（`s3-p2-manual-checklist.md`）签字为准；
- 发布说明不承诺未来排期。
